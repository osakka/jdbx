Permission Model Overview

JDBX uses a role-based access control (RBAC) system with fine-grained permissions:

  • Resource-based: Permissions are granted on specific resources (collections, APIs, etc.)
  • CRUD Operations: Create, Read, Update (Write), Delete permissions per resource
  • Admin Permission: Full control over the resource including permission management
  • Role Inheritance: Users inherit all permissions from their assigned roles
  • Default Roles: Admin (full access), Editor (CRUD), Viewer (read-only)
