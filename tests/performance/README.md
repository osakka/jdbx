# performance Tests

This directory contains tests for the performance components of JSONdb.

## Test Files

- `multi_thread_test.c`
- `multithreaded_ops.c`
- `test_api_performance.c`
- `test_database_performance.c`

## Makefiles

- `Makefile.multi_thread`
- `Makefile.multithreaded`

## Running Tests

Use the appropriate Makefile to run these tests, for example:

```
make -f Makefile.<testname>
```
