# js Tests

This directory contains tests for the js components of JSONdb.

## Test Files

- `db_js_test.c`
- `js_test.c`
- `minimal_js_test.c`
- `simple_js_test.c`
- `test_js_compilation.c`
- `test_js_integration.c`
- `test_js_modes.c`

## Makefiles

- `Makefile.db_js_test`
- `Makefile.js_integration`
- `Makefile.js_test`
- `Makefile.minimal_js_test`
- `Makefile.simple_js_test`

## Running Tests

Use the appropriate Makefile to run these tests, for example:

```
make -f Makefile.<testname>
```
